NEONHUB — инструкция для Android
================================
Файлы:
- index.html — сайт с тёмным неоновым дизайном, адаптивный для телефона.
- firebase-config.js — настройки Firebase и email владельца.
- firestore.rules — правила безопасности базы.

ВАЖНО: пока не вставлена конфигурация веб-приложения Firebase, сайт работает в демо-режиме. Реальная регистрация, облачная лента и админ-действия требуют настройки Firebase. Не добавляй сюда пароли Google или приватные ключи сервисных аккаунтов.

1. ДОБАВЬ WEB APP
- Открой https://console.firebase.google.com/ и выбери NeonHub.
- На странице проекта нажми значок </> (Web / Добавить приложение).
- Имя: NeonHub Web, затем Register app.
- Выбери Config и скопируй firebaseConfig.
- В файле firebase-config.js замени ВСТАВЬ_API_KEY, ВСТАВЬ_AUTH_DOMAIN, ВСТАВЬ_PROJECT_ID, ВСТАВЬ_STORAGE_BUCKET, ВСТАВЬ_MESSAGING_SENDER_ID, ВСТАВЬ_APP_ID на реальные значения.
- В NEONHUB_OWNER_EMAIL вставь свой email, с которым будешь регистрироваться.

2. СОЗДАЙ FIRESTORE
- Firebase Console -> ☰ -> Build / Создание -> Firestore Database.
- Create database -> Production mode -> выбери регион -> Create.
- После создания открой Rules / Правила.
- Скопируй весь текст из firestore.rules в редактор правил.
- Замени ВСТАВЬ_СВОЮ_ПОЧТУ в функции owner() на тот же email владельца.
- Нажми Publish / Опубликовать.
- Не используй открытые правила allow read, write: if true.

3. ПРОВЕРЬ AUTHENTICATION
- Authentication -> Sign-in method -> Email/Password должен быть включён.
- В Authentication -> Settings -> Authorized domains добавь домен сайта, если Firebase этого потребует.

4. ЗАГРУЗИ НА ХОСТИНГ
- Загрузи index.html и firebase-config.js в одну публичную папку сайта.
- firestore.rules лучше оставить отдельно; он нужен для копирования в Firebase, публиковать его на сайте не нужно.
- Открой сайт по HTTPS и обнови страницу.
- Зарегистрируйся под email владельца, указанным в обоих файлах, затем войди. Админ-пункт появится для этого email.

ЧТО ВКЛЮЧЕНО СЕЙЧАС
- Адаптивный тёмный дизайн, навигация, лента.
- Firebase регистрация, вход и восстановление пароля по email.
- Публикации через Firestore.
- Редактирование имени и описания профиля.
- Жалобы на публикации.
- Базовая админ-панель владельца и удаление публикаций.
- Страницы-заготовки музыки, медиа, сообществ и сообщений.

ЧТО ПОКА НУЖНО РЕАЛЬНО ДОРАБОТАТЬ
Личные сообщения, комментарии, лайки, загрузка файлов, блокировка аккаунтов и полноценная статистика не подключены к серверной логике. Их нужно добавлять с отдельными коллекциями, проверенными правилами и/или Cloud Functions. Не выдавай этот пакет за полностью готовую production-соцсеть, пока не протестированы права доступа.
